# ドローン航路システム 外部システム連携ライブラリ(Java版)

## 概要
- 外部システムへの情報取得や情報提供する機能群です。
- DIPS 2.0へのトークン発行や飛行禁止エリア情報及び飛行計画情報の取得、予約情報のメール配信、SWIM連携用Excelダウンロードをすることができます。

* DIPS 2.0と連携するには、事前にDIPS2.0へのクライアントID発行手続き、及びDIPSアカウントの作成が必要となります。
